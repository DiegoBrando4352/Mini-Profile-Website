## 📝 Overview

A two-page mini profile website built using only HTML and CSS. This project demonstrates semantic HTML structure, CSS Box Model, and Flexbox layout techniques.

## 🚀 Live Demo

🔗 **[View Live Website](https://DiegoBrando4352.github.io/Mini-Profile-Website/)**

## 📁 Pages

| Page | Description |
|------|-------------|
| **Home** | Personal profile with About Me section, Skills list, and Weekly Schedule table |
| **Contact** | Contact form with Name, Email, and Message fields |

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Box Model, Flexbox layout, and styling

## ✨ Features

- Semantic HTML elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- Responsive Flexbox card layout with `flex-wrap`
- CSS Box Model (margin, padding, border, border-radius)
- Working navigation links between pages
- Contact form with proper labels and inputs
